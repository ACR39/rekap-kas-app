Folder ini berisi database SQLite (kas.db) yang dibuat otomatis saat aplikasi dijalankan.

- kas.db tidak di-commit ke git (lihat .gitignore) supaya data pribadi tidak terunggah.
- Backup: Pengaturan -> Unduh kas.db, atau copy file kas.db saat aplikasi tidak dipakai.
- Reset total: hapus kas.db, lalu jalankan ulang aplikasi.
